# 🎥 AIM Video Creator (aim_video_creator)

Используй MCP-инструмент `aim_video_creator` для создания короткого видео по описанию или фотографии.

Аргументы: $ARGUMENTS

Действия:
- `prepare` — подготовить и проверить промпт без платной генерации
- `create` — отправить ролик в генерацию
- `status` — проверить прогресс по `videoId`
- `download` — сохранить готовый MP4
- `delete` — удалить задачу

Форматы: вертикаль `720x1280` / `1024x1792`, горизонталь `1280x720` / `1792x1024`.
Длительность: `4`, `8` или `12` секунд.
Фото передавай через `referenceImagePath` или `referenceImageUrl`, но не оба сразу.
