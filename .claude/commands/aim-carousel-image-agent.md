# 🖼️ Агент генерации карусели отдельными картинками (aim_create_carousel_image_agent)

Используй MCP инструмент `aim_create_carousel_image_agent`.

Аргументы: $ARGUMENTS

Обязательный параметр:
- `material` — исходный материал: текст, тезисы, сценарий или бриф.

Опционально:
- `slideCount` — количество отдельных слайдов/картинок (1-20, по умолчанию 7)
- `format` — `portrait` 1080×1350 или `square` 1080×1080
- `style` — визуальный стиль, например: GPT-like, luxury, editorial, 3D, minimal, neon
- `language` — `ru` или `en`
- `outputNaming` — шаблон имён файлов, например `slide_{NN}.png`
- `includeTextOnImage` — добавлять ли текст на изображение

Главное правило: генерируй каждый слайд отдельным запросом. Не объединяй все слайды в один коллаж/сетку/превью.
