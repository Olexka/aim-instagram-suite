# 🖼️ Агент генерации карусели отдельными картинками (aim_create_carousel_image_agent)

Используй MCP инструмент `aim_create_carousel_image_agent`.

Аргументы: $ARGUMENTS

Обязательный параметр:
- `slides` — массив отдельных слайдов:
  - `slideNumber` — номер слайда
  - `text` — точный текст текущего слайда
  - `visual` — описание изображения текущего слайда

Опционально:
- `format` — `portrait` 1080×1350 или `square` 1080×1080
- `style` — единый визуальный стиль, например GPT-like, luxury, editorial, 3D, minimal, neon
- `language` — `ru` или `en`
- `outputNaming` — шаблон имён файлов, например `slide_{NN}.png`
- `includeTextOnImage` — добавлять ли текст на изображение

Главное правило: каждый prompt должен содержать только один текущий слайд. Генерируй каждый слайд отдельным запросом. Не объединяй все слайды в один коллаж/сетку/превью.
